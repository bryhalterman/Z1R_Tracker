Z1R Tracker — OBS setup

Three pages. One goes on stream; the two docks are where you click.

Overlay → add as a Browser Source

Read-only and transparent, for compositing over the game capture. Every control is disabled on purpose. Append ?sections= to choose panels.

overlay.html

Dock → add as a Custom Browser Dock

Where you click: the items and the Item locations columns, with the seed form, the hint log and Export, Import and Reset in its header bar.

dock.html

Map → add as a second Custom Browser Dock

The two maps — the overworld and the dungeon room sheet — with the seed and hint log, so the maps can be sized properly and left alone instead of being scrolled past. Shares a run with the dock: a change in either shows in both.

map.html

Both must load from this same address. They sync through localStorage and a BroadcastChannel, which are scoped to an origin — two file:// pages do not share one in OBS, so keep using this server for both.
