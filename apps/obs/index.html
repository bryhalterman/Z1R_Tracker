Z1R Tracker — OBS setup

Two pages. One goes on stream, one is where you click.

Overlay → add as a Browser Source

Read-only and transparent, for compositing over the game capture. Every control is disabled on purpose. Append ?sections= to choose panels.

overlay.html

Dock → add as a Custom Browser Dock

The interactive half, with full tracking: seed, items, Triforce, locations, hints and the overworld map. Never on camera, so it carries everything.

dock.html

Both must load from this same address. They sync through localStorage and a BroadcastChannel, which are scoped to an origin — two file:// pages do not share one in OBS, so keep using this server for both.
